How the engine is organized

How the engine is built, how its modules start and stop, and how they depend on each other.

One library, many modules

The engine is a single static library, the CMake target Engine (CMakeLists.txt:26). Inside it, each engine system is a module: a folder of public headers under include/ and matching sources under src/, with its own C++ namespace.

Part Where What it is
Engine core include/Module.hpp · src/Module.cpp Starts and stops the modules, and runs the game loop (Engine::Run()). See Engine core.
Modules include/<Module>/ · src/<Module>/ Ten engine systems, e.g. Log, Filesystem and the renderer. See Engine modules.
Config Config/filesystem.json Settings files, read by the Filesystem module.

Include a module through its folder, e.g. #include <Log/Module.hpp>. Most modules have a Module.hpp that pulls in the rest of their public API.

Startup and shutdown

The engine core calls each module's init function directly, in a fixed order written in Engine::InitializePlugins(). At shutdown, Engine::TeardownPlugins() tears the modules down in roughly reverse order.

Startup (left), then the game loop, then shutdown (right). Source: src/Module.cpp:73.

Warning
Four modules are never initialized by the engine. Memory, CoreTypes, Input and GameplayFramework each have a Module() function, but Engine::InitializePlugins() does not call any of them. Memory's, CoreTypes' and Input's are currently empty. GameplayFramework::Module() registers the FColliderComponent and FMouseState ECS components (src/Gameplay/Module.cpp:18), so call it yourself if your game uses them. Likewise, ImGuiWrapper::TeardownModule() is never called at shutdown.

The game loop

Once started, Engine::Run() repeats these steps every frame until Input reports a quit request:

  1. Report the last frame's time (Engine::Globals::ReportRenderTime_NS).
  2. Read input: Input::UpdateInputs(). Stop if Input::ShouldQuit().
  3. Update the ECS world: ECS::UpdateEntities(deltaTime).
  4. Render: Renderer::StartRenderFrame(), CoreEditor::BeginRender(), Renderer::RenderFrame(), CoreEditor::EndRender().
  5. Wait out the rest of the frame. The loop is capped at 500 frames per second.

Engine exampleThe loop bodysrc/Module.cpp:40

while (bTickRunning) {
ZoneNamedN(Tick, "Engine::Tick", true);
uint64_t currTime = SDL_GetTicksNS();
Globals::ReportRenderTime_NS(renderingNs);
Input::UpdateInputs();
if (Input::ShouldQuit()) {
bTickRunning = false;
break;
}
ECS::UpdateEntities(Globals::GetDeltaTime());
Renderer::StartRenderFrame();
CoreEditor::BeginRender();
Renderer::RenderFrame();
CoreEditor::EndRender();
renderingNs = SDL_GetTicksNS() - currTime;
if (renderingNs < nsPerFrame)
{
ZoneNamedN(TickWait, "Engine::Tick::Wait", true);
SDL_DelayNS(nsPerFrame - renderingNs);
renderingNs = SDL_GetTicksNS() - currTime;
}
FrameMark;
}
