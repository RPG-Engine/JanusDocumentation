Examples

Complete programs that use only Janus. Each is a single .cpp file, needs no image or data files (textures are generated in code), and was compiled and run against the documented engine commit.

Build them all at once from Engine/Documentation/examples; see Build and run the examples. Each page shows a screenshot, explains the important parts, and ends with the full source.

Game examples

Three small games that show how the pieces fit together. They are meant to be read, not to be good games.

DodgeAvoid falling blocks. Input, spawning on a timer, destroying entities, collision with a query, a HUD. SnakeGrid movement on a fixed time step, game data separate from presentation, reusing entities. BreakoutA bouncing ball, paddle angles, breaking bricks, lives and a win condition.

ECS examples

Focused examples of common mechanics built with entities, components and systems.

Moving entitiesInput to velocity to position, bouncing, and a camera that follows the player. Spawning and destroyingSpawners, prefabs, lifetimes and fading out. Components, queries and observersThe component macros, tags, queries, observers, a custom phase and global settings. Collision and mouse hoverColliders, sliding along walls, the collider overlay and hovering with the mouse.

The parts every example shares

Every graphical example starts with the same few helpers, because the renderer needs them (see The minimum for a visible game):

  • RegisterSolidTexture("CollisionTexture", 8) and RegisterSolidTexture("White", 8) before Engine::InitializePlugins(): textures made in code, so no image files are needed. Sprites tint the white texture with their colour.
  • CreateCameraAndBackground(...): a fixed camera showing 320 × 180 world units, a light that covers the screen, and a full-screen sprite on the Background layer.
  • A small HUD tool that collapses the Dear ImGui demo window and shows the controls.
  • std::quick_exit(0) at the end of main(), to avoid a crash after shutdown (Shutdown).
