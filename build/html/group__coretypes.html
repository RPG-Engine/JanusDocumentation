How to use

Frame timing

Engine::Globals::GetDeltaTime() returns how long the last frame took, in seconds, and Engine::Globals::GetFPS() the matching frame rate. Inside a flecs system, it.delta_time() gives the same value.

Showing the frame rate in a tool windowexamples/modules/EditorTools.cpp

// An editor tool is a class with a Draw_Internal() function. The engine calls it
// every frame while the tool is open, between ImGui::NewFrame() and rendering,
// so any ImGui call works here.
class SpawnerTool : public ImGUIWrapper::IEditorTool {
public:
int SpawnedCount = 0;
protected:
void Draw_Internal() override {
ImGui::SetWindowCollapsed("Dear ImGui Demo", true, ImGuiCond_Once);
// Positions are in screen coordinates (multi-viewport is on),
// so place it relative to the main window.
// A window dragged outside the main window becomes a separate OS window.
const ImGuiViewport* viewport = ImGui::GetMainViewport();
const ImVec2 position {viewport->Pos.x + 40.f, viewport->Pos.y + 260.f};
ImGui::SetNextWindowPos(position, ImGuiCond_FirstUseEver);
ImGui::SetNextWindowSize({330.f, 0.f}, ImGuiCond_FirstUseEver);
// Passing &bOpen gives the window a close button that closes the tool.
ImGui::Begin("Spawner", &bOpen);
const double fps = Engine::Globals::GetFPS();
const double frameMs = Engine::Globals::GetDeltaTime() * 1000.0;
ImGui::Text("%.0f FPS (%.2f ms)", fps, frameMs);
ImGui::Separator();
static float color[4] = {0.4f, 0.8f, 1.f, 1.f};
static float size = 12.f;
static int count = 5;
ImGui::ColorEdit4("Colour", color);
ImGui::SliderFloat("Size", &size, 4.f, 40.f);
ImGui::SliderInt("Count", &count, 1, 50);
if (ImGui::Button("Spawn")) {
static std::mt19937 rng {1};
std::uniform_real_distribution<float> x(0.f, ScreenW - size);
std::uniform_real_distribution<float> y(0.f, ScreenH - size);
const SDL_FColor tint {color[0], color[1], color[2], color[3]};
flecs::entity last;
for (int i = 0; i < count; ++i) {
const std::string name = "Spawned " + std::to_string(SpawnedCount++);
last = ECS::GetWorld().entity(name.c_str())
.set<FTransformComponent>({ .Location = {x(rng), y(rng), 0.f} })
.set<FTexture2DComponent>({
.Sprite = { .SpriteSheet = {"White"} },
.TextureSize = {size, size},
.Color = tint,
})
.set<FRenderingComponent>({ .RenderLayer = Renderer::Entities });
}
ECS::SelectEntity(last); // show the newest one in the Entity Debugger
Log::EditorDemo::Info("Spawned {} entities", count);
}
ImGui::SameLine();
if (ImGui::Button("Clear")) {
// Tools run outside the ECS update, so changes are applied immediately.
// Defer them while iterating, so destroying entities doesn't disturb
// the iteration.
flecs::world& world = ECS::GetWorld();
world.defer([&world] {
world.each([](flecs::entity entity, const FTexture2DComponent&) {
const std::string name = entity.name().c_str();
if (name.starts_with("Spawned")) {
entity.destruct();
}
});
});
}
ImGui::Separator();
ImGui::TextDisabled("Built-in tools");
if (ImGui::Button("Show FPS Counter")) {
// Reopens the existing instance
CoreEditor::Open<CoreEditor::DebugStatsEditor>();
}
ImGui::End();
}
void OnOpenStateChanged(bool bIsOpen) override {
Log::EditorDemo::Info("Spawner tool {}", bIsOpen ? "opened" : "closed");
}
};

Textures

A Graphics::STexture2D holds an image in memory (Surface, an SDL_Surface in RGBA byte order) and, once uploaded, on the GPU (LoadedGPUTexture). Get one by loading an image file, or build one in code:

A texture generated in codeexamples/modules/AssetsAndMemory.cpp

// Builds a texture in code and registers it like a file.
// SDL_PIXELFORMAT_ABGR8888 is the byte order (R, G, B, A) the renderer uploads,
// the same format image files are converted to.
static void RegisterCheckerTexture(const std::string& AssetPath, int Size,
int Squares) {
SDL_Surface* surface = SDL_CreateSurface(Size, Size, SDL_PIXELFORMAT_ABGR8888);
const Uint32 light = SDL_MapSurfaceRGBA(surface, 235, 235, 240, 255);
const Uint32 dark = SDL_MapSurfaceRGBA(surface, 70, 80, 110, 255);
const int cell = Size / Squares;
for (int y = 0; y < Squares; ++y) {
for (int x = 0; x < Squares; ++x) {
const bool bLight = (x + y) % 2 == 0;
const SDL_Rect rect {x * cell, y * cell, cell, cell};
SDL_FillSurfaceRect(surface, &rect, bLight ? light : dark);
}
}
TObjectPtr<Graphics::STexture2D> texture; // TObjectPtr<T>() creates a new T
texture->Surface = surface;
texture->Width = static_cast<float>(Size);
texture->Height = static_cast<float>(Size);
texture->AssetPath = AssetPath;
TObjectPtr<Filesystem::SAssetData> assetData;
assetData->AssetPath = AssetPath; // the key GetAssetData() looks up
assetData->AssetName = AssetPath;
assetData->AssetType = Filesystem::TEXTURE;
assetData->ObjectData = texture; // already loaded: LoadFile() returns it
Filesystem::RegisterAssetData(assetData);
}

Sprites refer to textures through a Graphics::SSprite inside Components::FTexture2DComponent: the texture's asset path plus the part of it to draw (see Renderer).

Levels

World::GenerateLevel(projectPath, levelName) builds a World::SLevel from an LDtk project saved with separate level files:

Argument Example File it loads
projectPath "Levels/MyWorld/MyWorld" Resources/Levels/MyWorld/MyWorld.ldtk
levelName "Level_0" Resources/Levels/MyWorld/MyWorld/Level_0.ldtkl

For each LDtk layer it records the tiles (auto-layer and grid tiles), loads the layer's tileset image as a Graphics::STilemap, and turns IntGrid values into World::SGridTile cells. An entity named PlayerStart sets World::SLevel::PlayerStart (src/Types/World.cpp:14).

Then draw it and get its collision rectangles with Renderer::LoadLevel(), and remember it with World::SetCurrentLevel(). ProtoRPG loads its level this way:

auto level = World::GenerateLevel("Levels/PoutineDetective/PoutineDetectiveWorld",
"Diner");
Collisions = Renderer::LoadLevel(level);
World::SetCurrentLevel(level);

Debug colliders

CoreTypes::bShouldDisplayDebugColliders switches the renderer's debug-collider overlay on and off. The engine declares an input action for it, Input::Actions::ToggleDebugColliders, but binds no key and does not toggle the flag itself. See Collision and mouse hover.

Things to watch out for

  • Graphics::SSpriteAnimation and Graphics::SGraphicsShader are data only: nothing in the engine plays animations or loads shaders through them at this commit.
  • World::GenerateLevel skips IntGrid collision for a layer named TerrainInt and gives a layer named Wall_Top a higher ZDepth, which the renderer does not use. These names come from ProtoRPG's levels.
  • Graphics::GetTile uses Row and Col directly as the rectangle's position; they are not multiplied by the tile size.
