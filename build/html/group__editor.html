How to use

An editor tool is a class derived from ImGUIWrapper::IEditorTool with a Draw_Internal() function full of ImGui calls. Every frame, between ImGui::NewFrame() and rendering, the engine calls Draw_Internal() on each open tool (src/Editor/Module.cpp:41). That makes tools the place for debug windows and for game UI such as a score display.

1. Write the tool:

A tool with buttons, sliders and a colour pickerexamples/modules/EditorTools.cpp

// An editor tool is a class with a Draw_Internal() function. The engine calls it
// every frame while the tool is open, between ImGui::NewFrame() and rendering,
// so any ImGui call works here.
class SpawnerTool : public ImGUIWrapper::IEditorTool {
public:
int SpawnedCount = 0;
protected:
void Draw_Internal() override {
ImGui::SetWindowCollapsed("Dear ImGui Demo", true, ImGuiCond_Once);
// Positions are in screen coordinates (multi-viewport is on),
// so place it relative to the main window.
// A window dragged outside the main window becomes a separate OS window.
const ImGuiViewport* viewport = ImGui::GetMainViewport();
const ImVec2 position {viewport->Pos.x + 40.f, viewport->Pos.y + 260.f};
ImGui::SetNextWindowPos(position, ImGuiCond_FirstUseEver);
ImGui::SetNextWindowSize({330.f, 0.f}, ImGuiCond_FirstUseEver);
// Passing &bOpen gives the window a close button that closes the tool.
ImGui::Begin("Spawner", &bOpen);
const double fps = Engine::Globals::GetFPS();
const double frameMs = Engine::Globals::GetDeltaTime() * 1000.0;
ImGui::Text("%.0f FPS (%.2f ms)", fps, frameMs);
ImGui::Separator();
static float color[4] = {0.4f, 0.8f, 1.f, 1.f};
static float size = 12.f;
static int count = 5;
ImGui::ColorEdit4("Colour", color);
ImGui::SliderFloat("Size", &size, 4.f, 40.f);
ImGui::SliderInt("Count", &count, 1, 50);
if (ImGui::Button("Spawn")) {
static std::mt19937 rng {1};
std::uniform_real_distribution<float> x(0.f, ScreenW - size);
std::uniform_real_distribution<float> y(0.f, ScreenH - size);
const SDL_FColor tint {color[0], color[1], color[2], color[3]};
flecs::entity last;
for (int i = 0; i < count; ++i) {
const std::string name = "Spawned " + std::to_string(SpawnedCount++);
last = ECS::GetWorld().entity(name.c_str())
.set<FTransformComponent>({ .Location = {x(rng), y(rng), 0.f} })
.set<FTexture2DComponent>({
.Sprite = { .SpriteSheet = {"White"} },
.TextureSize = {size, size},
.Color = tint,
})
.set<FRenderingComponent>({ .RenderLayer = Renderer::Entities });
}
ECS::SelectEntity(last); // show the newest one in the Entity Debugger
Log::EditorDemo::Info("Spawned {} entities", count);
}
ImGui::SameLine();
if (ImGui::Button("Clear")) {
// Tools run outside the ECS update, so changes are applied immediately.
// Defer them while iterating, so destroying entities doesn't disturb
// the iteration.
flecs::world& world = ECS::GetWorld();
world.defer([&world] {
world.each([](flecs::entity entity, const FTexture2DComponent&) {
const std::string name = entity.name().c_str();
if (name.starts_with("Spawned")) {
entity.destruct();
}
});
});
}
ImGui::Separator();
ImGui::TextDisabled("Built-in tools");
if (ImGui::Button("Show FPS Counter")) {
// Reopens the existing instance
CoreEditor::Open<CoreEditor::DebugStatsEditor>();
}
ImGui::End();
}
void OnOpenStateChanged(bool bIsOpen) override {
Log::EditorDemo::Info("Spawner tool {}", bIsOpen ? "opened" : "closed");
}
};

2. Open it once, after Engine::InitializePlugins(). CoreEditor::Open<T>() creates the tool the first time and returns the same instance on later calls:

Openexamples/modules/EditorTools.cpp

// Open<T>() creates the tool the first time,
// and returns the same instance afterwards.
TObjectPtr<SpawnerTool> spawner = CoreEditor::Open<SpawnerTool>();

3. Close and reopen it from game code with Close() and Open(); a closed tool keeps its state. Passing &bOpen to ImGui::Begin gives the window a close button that does the same:

Toggling a tool with a keyexamples/modules/EditorTools.cpp

// Tools can be closed and reopened from game code. A closed tool keeps its state.
world.system("ToggleSpawner").run([spawner](flecs::iter& it) {
if (Input::IsActionTriggered(Input::Actions::ToggleSpawner)) {
if (spawner->bOpen) {
spawner->Close();
} else {
spawner->Open();
}
}
while (it.next()) {}
});

Override OnOpenStateChanged(bool) to react when a tool opens or closes.

Component panels in the Entity Debugger:

  • FTransformComponent has a move gizmo drawn over the game: drag it to move the entity (src/Editor/EntityEditorTool.cpp:61).
  • FTexture2DComponent has a texture drop-down, its UV fields, Open Sprite Sheet, and Update (src/Editor/EntityEditorTool.cpp:82).
  • Your own components get a panel from the DEFINE_COMPONENT macros (Defining components).

Reopen a built-in tool you closed with CoreEditor::Open<CoreEditor::DebugStatsEditor>() (or EntityEditorTool).

Game UI with tools

The examples' HUDs are tools that draw a small window with no title bar and no input, anchored to a corner of the game window. They also collapse the ImGui demo window once:

The Dodge HUDexamples/games/Dodge.cpp

// ---- HUD ----------------------------------------------------------------------
// Editor tools are drawn every frame between ImGui::NewFrame() and the render, so
// they are the place for game UI too. Open it once with CoreEditor::Open<DodgeHud>().
class DodgeHud : public ImGUIWrapper::IEditorTool {
protected:
void Draw_Internal() override {
// The engine always shows the Dear ImGui demo window.
// Collapse it once so it doesn't cover the game.
ImGui::SetWindowCollapsed("Dear ImGui Demo", true, ImGuiCond_Once);
const ImGuiViewport* viewport = ImGui::GetMainViewport();
const ImVec2 topRight {viewport->Pos.x + viewport->Size.x - 16.f,
viewport->Pos.y + 16.f};
ImGui::SetNextWindowPos(topRight, ImGuiCond_Always, {1.f, 0.f});
const ImGuiWindowFlags flags = ImGuiWindowFlags_NoDecoration
| ImGuiWindowFlags_AlwaysAutoResize
| ImGuiWindowFlags_NoInputs;
ImGui::Begin("Dodge", nullptr, flags);
ImGui::Text("Time %5.1f s Best %5.1f s", Game.Survived, Game.Best);
if (Game.bGameOver) {
ImGui::TextColored({1.f, 0.4f, 0.4f, 1.f}, "Hit! Press R to restart.");
} else {
ImGui::TextDisabled("A / D or arrow keys to move");
}
ImGui::End();
}
};

Things to watch out for

  • Tools are drawn outside the ECS update, so entity changes made in Draw_Internal() happen immediately. Wrap loops that create or destroy entities in ECS::GetWorld().defer(...).
  • CoreEditor::Open<T>() keeps one instance per tool type; you cannot open two windows of the same tool class.
  • Tools are never destroyed or unregistered; closing only hides them.
  • With multi-viewport on, place windows relative to ImGui::GetMainViewport()->Pos; see ImGuiWrapper.
  • The Entity Debugger's component headers cannot be collapsed (include/Gameplay/ECS/Components.hpp:43).
