How to use

Call the three functions in this order from main():

  1. Before Engine::InitializePlugins(): register anything the engine needs while it starts. At this commit that is a texture asset called CollisionTexture (see The minimum for a visible game).
  2. Engine::InitializePlugins() starts SDL and the engine modules and opens the window.
  3. Set up your game: register components, bind input, create entities and systems, open editor tools.
  4. Engine::Run() runs the game loop. It returns when the window is closed (or an SDL_EVENT_QUIT is pushed).
  5. Engine::TeardownPlugins() shuts the modules down.

The shape of every Janus programexamples/modules/HelloJanus.cpp

// The renderer loads "CollisionTexture" while the engine starts,
// so register it first.
RegisterSolidTexture("CollisionTexture", 8);
RegisterSolidTexture("White", 8);
Engine::InitializePlugins();
flecs::world& world = ECS::GetWorld();
// Camera: shows world units (0,0) to (320,180). Boundaries of 0 pin it in place.
// The light on the same entity is large enough to light the whole screen.
world.entity("Camera")
.set<FTransformComponent>({})
.set<FCameraComponent>({ .CameraSize = {320, 180}, .Boundaries = {0, 0, 0, 0} })
.set<FLightComponent>({ .Radius = 100.f, .Intensity = 2.4f });
// Background: a full-screen sprite on the Background layer.
world.entity("Background")
.set<FTransformComponent>({})
.set<FTexture2DComponent>({
.Sprite = { .SpriteSheet = {"White"} },
.TextureSize = {320, 180},
.Color = {0.10f, 0.12f, 0.18f, 1.f} })
.set<FRenderingComponent>({ .RenderLayer = Renderer::Background });
// A 32x32 orange square. Location is its top-left corner, in world units.
world.entity("Square")
.set<FTransformComponent>({ .Location = {48, 100, 0} })
.set<FTexture2DComponent>({
.Sprite = { .SpriteSheet = {"White"} },
.TextureSize = {32, 32},
.Color = {1.f, 0.55f, 0.1f, 1.f} })
.set<FRenderingComponent>({ .RenderLayer = Renderer::Entities });
Log::Hello::Info("Hello, Janus! Close the window to quit.");
Engine::Run(); // returns when the window is closed
Engine::TeardownPlugins();
// Known issue: returning from main() after TeardownPlugins() crashes in static
// destructors.
// Exit without running them (the engine has already flushed its logs).
std::quick_exit(0);

Warning
Returning from main() after Engine::TeardownPlugins() crashes in static destructors at this commit. End main() with std::quick_exit(0) as the examples do. See Shutdown.

The diagrams in How the engine is organized show the same thing visually.

Things to watch out for

  • Four modules are not started by InitializePlugins(): Memory, CoreTypes and Input have nothing to start, but GameplayFramework registers components, so call GameplayFramework::Module() yourself if you use colliders or mouse hover.
  • If SDL_Init fails, InitializePlugins() logs the SDL error and calls throw; with no active exception, which terminates the program (src/Module.cpp:76).
  • Run() keeps no state you can reset: call it once.
  • The frame time reported for frame N is the time frame N − 1 took, including the wait. Read it with Engine::Globals::GetDeltaTime() (CoreTypes).

void InitializePlugins() {
ZoneScoped;
if (SDL_Init(SDL_INIT_VIDEO | SDL_INIT_AUDIO) == false) {
Log::Engine::Error(SDL_GetError());
throw;
}
Log::Engine::Info("========= Janus Engine Initializing =========");
Log::Module();
Filesystem::InitializeAllResources();
ImGuiWrapper::Module();
ECS::Module();
Renderer::Module();
CoreEditor::ModuleStartup();
Log::Engine::Info("Engine initialization complete!");
}

◆ Run()

void Engine::Run ( )

Each frame calls Input::UpdateInputs(), then ECS::UpdateEntities() with the last frame's duration in seconds, then renders. The loop is capped at 500 frames per second. To quit from code, push an SDL_EVENT_QUIT event (see Input).

Defined at src/Module.cpp:30. The loop body is shown in How the engine is organized.

◆ TeardownPlugins()

void Engine::TeardownPlugins ( )

Call it after Engine::Run() returns. Defined at src/Module.cpp:95. Log::TeardownModule() runs last, so modules can still log while shutting down.
