Input

Named input actions. More...

Overview

You declare an action, bind keys to it (on press, while held, or on release), and read its value from your systems.

Sourceinclude/Input/ · src/Input/
Include#include <Input/Module.hpp>
NamespacesInput; your actions live in Input::Actions
Started byNothing to start: Input::Module() is empty. Engine::Run() calls Input::UpdateInputs() every frame.
ExamplesInput · Moving entities · every game

How to use

1. Declare an action at global scope with DEFINE_INPUT_ACTION: a name and the type of value it produces. It becomes Input::Actions::<Name>.

Declaring actionsexamples/modules/Input.cpp

// DEFINE_INPUT_ACTION(Name, Type) creates Input::Actions::Name.
// Its bindings' values are added up (ADD).
DEFINE_INPUT_ACTION(Move, glm::vec2)
DEFINE_INPUT_ACTION(SpacePressed, bool)
DEFINE_INPUT_ACTION(SpaceHeld, bool)
DEFINE_INPUT_ACTION(SpaceReleased, bool)
DEFINE_INPUT_ACTION(Save, bool)
DEFINE_INPUT_ACTION(Confirm, bool)
DEFINE_INPUT_ACTION(Quit, bool)
// With OVERRIDE the value is the last triggered binding's value, not a sum.
// Untriggered: 0.
DEFINE_INPUT_ACTION_WITH_PARAMS(SpeedBoost, float, OVERRIDE)

2. Bind keys with AddInputBindings_Press, AddInputBindings_Hold or AddInputBindings_Release. Each binding is a key (an SDL_Scancode) and the value it contributes:

Binding keysexamples/modules/Input.cpp

// Hold: active every frame the key is down.
Input::AddInputBindings_Hold(&Input::Actions::Move, {
{SDL_SCANCODE_UP, {0, -1}}, {SDL_SCANCODE_DOWN, {0, 1}},
{SDL_SCANCODE_LEFT, {-1, 0}}, {SDL_SCANCODE_RIGHT, {1, 0}},
});
Input::AddInputBindings_Hold(&Input::Actions::SpeedBoost, {
{SDL_SCANCODE_LSHIFT, 2.5f}, {SDL_SCANCODE_RSHIFT, 2.5f},
});
// The same key can drive several actions.
// Press: the frame it goes down. Release: the frame it comes up.
const SDL_Scancode space = SDL_SCANCODE_SPACE;
Input::AddInputBindings_Press(&Input::Actions::SpacePressed, {{space, true}});
Input::AddInputBindings_Hold(&Input::Actions::SpaceHeld, {{space, true}});
Input::AddInputBindings_Release(&Input::Actions::SpaceReleased, {{space, true}});
// A combo: one binding with several keys.
// For hold bindings, all of them must be down.
Input::AddInputBindings_Hold(&Input::Actions::Save, {
Input::SInputBinding<bool>({SDL_SCANCODE_LCTRL, SDL_SCANCODE_S}, true),
});
Input::AddInputBindings_Press(&Input::Actions::Confirm, {
{SDL_SCANCODE_RETURN, true},
});
Input::AddInputBindings_Press(&Input::Actions::Quit, {
{SDL_SCANCODE_ESCAPE, true},
});

3. Read the action in a system. Input is read at the start of each frame, before systems run:

Call Returns
Input::IsActionTriggered(Input::Actions::Jump) true if any of its bindings triggered this frame
Input::GetValue(Input::Actions::Move) The combined value of the bindings that triggered (see Values and operators)

Polling actions in a systemexamples/modules/Input.cpp

// Most game code polls actions from a system.
// Input is read before the systems run each frame.
world.system<FTransformComponent, FTexture2DComponent>("PollInput")
.each([](flecs::entity entity, FTransformComponent& transform,
FTexture2DComponent& sprite) {
const float dt = entity.world().delta_time();
const std::string name = entity.name().c_str();
if (name == "Player") {
const float boost = Input::GetValue(Input::Actions::SpeedBoost);
const glm::vec2 direction = Input::GetValue(Input::Actions::Move);
const glm::vec2 move = direction * 60.f * std::max(1.f, boost) * dt;
glm::vec3& location = transform.Location;
location.x = std::clamp(location.x + move.x, 0.f, ScreenW - 16.f);
location.y = std::clamp(location.y + move.y, 0.f, ScreenH - 16.f);
bSaving = Input::IsActionTriggered(Input::Actions::Save);
const SDL_FColor savingColor {0.5f, 1.f, 0.5f, 1.f};
const SDL_FColor normalColor {0.4f, 0.9f, 1.f, 1.f};
sprite.Color = bSaving ? savingColor : normalColor;
return;
}
if (name == "PressLight") {
if (Input::IsActionTriggered(Input::Actions::SpacePressed)) {
PressedGlow = 1.f;
}
PressedGlow = std::max(0.f, PressedGlow - dt * 2.f);
const float glow = PressedGlow;
sprite.Color = {0.2f + glow * 0.8f, 0.2f + glow * 0.6f, 0.2f, 1.f};
} else if (name == "HoldLight") {
const bool bHeld = Input::IsActionTriggered(Input::Actions::SpaceHeld);
HeldGlow = bHeld ? 1.f : 0.f;
sprite.Color = {0.2f, 0.2f + HeldGlow * 0.8f, 0.2f, 1.f};
} else if (name == "ReleaseLight") {
if (Input::IsActionTriggered(Input::Actions::SpaceReleased)) {
ReleasedGlow = 1.f;
}
ReleasedGlow = std::max(0.f, ReleasedGlow - dt * 2.f);
const float glow = ReleasedGlow;
sprite.Color = {0.2f, 0.2f + glow * 0.5f, 0.2f + glow * 0.8f, 1.f};
}
});

Or register a callback that runs when the action triggers:

A callbackexamples/modules/Input.cpp

// A callback runs during Input::UpdateInputs() on every frame the action triggers.
// Register one callback per action: each extra one makes all of them run again.
Input::RegisterActionCallback<bool>(&Input::Actions::Confirm, [](const bool&) {
++ConfirmCount;
Log::InputDemo::Info("Confirm pressed ({} times)", ConfirmCount);
});

When a binding triggers

Binding type Triggers on Typical use
PRESS The frame the key goes down, and every keyboard auto-repeat while it is held Jump, confirm, toggle
HOLD Every frame the key is down Movement, charging
RELEASE The frame the key comes up Release a charged attack

Keys are SDL scancodes: physical key positions, named after a US keyboard. SDL_SCANCODE_W is the key in W's position on any layout. The full list is in SDL_scancode.h.

A binding can list several keys. For a HOLD binding all of them must be down, which makes key combinations:

Input::AddInputBindings_Hold(&Input::Actions::Save, {
Input::SInputBinding<bool>({SDL_SCANCODE_LCTRL, SDL_SCANCODE_S}, true),
});

Values and operators

GetValue starts from a zero value (TValueType{}) and applies the value of every triggered binding, in the order they were added, using the action's operator (include/Input/Module.hpp:71):

Operator Result Declare with
ADD (default) Sum of the triggered bindings' values. Arrow keys (0,-1) + (1,0) give (1,-1). DEFINE_INPUT_ACTION(Name, Type)
OVERRIDE The value of the last triggered binding. Zero if none. DEFINE_INPUT_ACTION_WITH_PARAMS(Name, Type, OVERRIDE)
SUBTRACT Zero minus each triggered value ..._WITH_PARAMS(Name, Type, SUBTRACT)
MULTIPLY, DIVIDE Always zero, because they start from zero —

Any type that supports += and can be zero-initialized works: bool, float, int, glm::vec2, ... For bool actions use Input::IsActionTriggered(); GetValue on a bool action works but makes MSVC warn (C4804).

Quitting

Input::UpdateInputs() sets the quit flag when SDL reports a quit event (closing the window), and Engine::Run() then stops. To quit from your own code, push that event:

Quit on Escapeexamples/modules/Input.cpp

// Input::ShouldQuit() becomes true when SDL sees a quit event (closing the window).
// To quit from code, push one yourself; Engine::Run() returns on the next frame.
world.system("QuitOnEscape").run([](flecs::iter& it) {
if (Input::IsActionTriggered(Input::Actions::Quit)) {
SDL_Event quit {};
quit.type = SDL_EVENT_QUIT;
SDL_PushEvent(&quit);
}
while (it.next()) {}
});

Things to watch out for

  • Keyboard only. Gamepad buttons can be added to bindings, but they are never checked (src/Input/Module.cpp:100).
  • Typing in an ImGui text field also triggers game actions. The engine passes events to ImGui but does not check whether ImGui wants the keyboard (src/Input/Module.cpp:44).
  • Register one callback per action. Each callback runs once for every callback registered on the same action: with two callbacks, both run twice (include/Input/Module.hpp:96).
  • Callbacks are checked every frame for every registered callback, triggered or not.
  • PRESS repeats while the key is held (operating-system key repeat). Track the previous state yourself if you need exactly one trigger per press.
