How to use

TObjectPtr<T> owns a heap-allocated T together with a use count. Copies share the object; when the last copy goes away, the object is deleted. In Debug builds each allocation is reported to the Tracy profiler's memory view.

TObjectPtr in practiceexamples/modules/AssetsAndMemory.cpp

// Any type can live in a TObjectPtr.
// Types derived from SAsset can also be loaded by the Filesystem module.
struct SInventory {
std::vector<std::string> Items;
};
// TObjectPtr<T> is a reference-counted pointer.
// Copies share the object; the last one deletes it.
TObjectPtr<SInventory> inventory; // creates a new SInventory
inventory->Items = {"sword", "shield"};
TObjectPtr<SInventory> sameInventory = inventory; // a second reference to it
sameInventory->Items.push_back("potion");
Log::Assets::Info("Items: {} (both pointers see {})",
inventory->Items.size(), sameInventory->Items.size());
TObjectPtr<SInventory> empty = nullptr; // an empty pointer
Log::Assets::Info("empty.IsValid() = {}", empty.IsValid());
sameInventory.Clear(); // drop one reference
Log::Assets::Info("After Clear: inventory valid = {}, sameInventory valid = {}",
inventory.IsValid(), sameInventory.IsValid());
// CastTo converts between related types
// (a static_cast: the object must really be of that type).
TObjectPtr<STextFileAsset> text;
text->Data = "hello";
TObjectPtr<SAsset> asBase = text; // derived -> base is implicit
TObjectPtr<STextFileAsset> asText = CastTo<STextFileAsset>(asBase);
Log::Assets::Info("CastTo round trip: {}", asText->Data);

You write You get
TObjectPtr<T> p; A new T, default-constructed. A default TObjectPtr is never empty.
TObjectPtr<T> p = nullptr; An empty pointer. p.IsValid() is false.
TObjectPtr<T> p(args...); A new T built from args (the constructor is explicit).
TObjectPtr<T> p = someT; A new T copied from someT.
TObjectPtr<T> q = p; A second reference to the same object.
TObjectPtr<Base> b = derivedPtr; A reference to the same object, as its base type.
CastTo<Derived>(basePtr) A reference to the same object, as a derived type. Unchecked, like static_cast.
p.Clear(); or p = nullptr; Drops this reference; deletes the object if it was the last.
p->Member, p.Raw() Access the object. Raw() returns the plain pointer.
p == q true if both point to the same object.

The engine uses TObjectPtr for assets (TObjectPtr<Graphics::STexture2D>), registry entries (TObjectPtr<Filesystem::SAssetData>), editor tools and render layers.

Things to watch out for

  • TObjectPtr<T> x; allocates. Write = nullptr when you want an empty pointer, for example for a member that is filled in later.
  • Assigning over a pointer that already holds an object does not release that object (include/Memory/Janitors.hpp:95). The old object is never deleted. Call Clear() first if the pointer may already hold something you want released.
  • Constructing from a T&& copies the object instead of moving it (include/Memory/Janitors.hpp:40).
  • CastTo on an empty pointer crashes: it increments the use count without checking (include/Memory/Janitors.hpp:124).
  • operator* does not compile if you use it (include/Memory/Janitors.hpp:120). Use -> or Raw().
  • The use count is a plain int: don't share one TObjectPtr object between threads.
