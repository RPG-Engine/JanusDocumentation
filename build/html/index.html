Janus Engine documentation

Janus is a C++26 engine for 2D games. Games are built from entities and components with flecs, drawn by a batched sprite renderer on SDL3's GPU API, and inspected live with Dear ImGui editor tools. It compiles into a single static library that your game links.

What a Janus game looks like

A game is an ordinary main() that starts the engine, creates entities, adds systems and runs the loop. This is the whole of the Hello Janus example, minus the texture helper:

Hello Janus: main()examples/modules/HelloJanus.cpp

// The renderer loads "CollisionTexture" while the engine starts,
// so register it first.
RegisterSolidTexture("CollisionTexture", 8);
RegisterSolidTexture("White", 8);
Engine::InitializePlugins();
flecs::world& world = ECS::GetWorld();
// Camera: shows world units (0,0) to (320,180). Boundaries of 0 pin it in place.
// The light on the same entity is large enough to light the whole screen.
world.entity("Camera")
.set<FTransformComponent>({})
.set<FCameraComponent>({ .CameraSize = {320, 180}, .Boundaries = {0, 0, 0, 0} })
.set<FLightComponent>({ .Radius = 100.f, .Intensity = 2.4f });
// Background: a full-screen sprite on the Background layer.
world.entity("Background")
.set<FTransformComponent>({})
.set<FTexture2DComponent>({
.Sprite = { .SpriteSheet = {"White"} },
.TextureSize = {320, 180},
.Color = {0.10f, 0.12f, 0.18f, 1.f} })
.set<FRenderingComponent>({ .RenderLayer = Renderer::Background });
// A 32x32 orange square. Location is its top-left corner, in world units.
world.entity("Square")
.set<FTransformComponent>({ .Location = {48, 100, 0} })
.set<FTexture2DComponent>({
.Sprite = { .SpriteSheet = {"White"} },
.TextureSize = {32, 32},
.Color = {1.f, 0.55f, 0.1f, 1.f} })
.set<FRenderingComponent>({ .RenderLayer = Renderer::Entities });
Log::Hello::Info("Hello, Janus! Close the window to quit.");
Engine::Run(); // returns when the window is closed
Engine::TeardownPlugins();
// Known issue: returning from main() after TeardownPlugins() crashes in static
// destructors.
// Exit without running them (the engine has already flushed its logs).
std::quick_exit(0);

From examples/modules/HelloJanus.cpp, which is compiled and run against the documented commit.

What the engine gives you

Area What you get Module
Game objects flecs entities, components and systems; component macros with reflection and editor panels ECS
Drawing Batched sprites in five layers, sprite-sheet cells, tint, rotation, Y-sorting, a camera, 2D lights Renderer
Input Named actions with press, hold and release bindings and value operators Input
Assets A registry of every file under Resources/, typed loaders, LDtk level import Filesystem
Tools Dear ImGui with docking, an Entity Debugger, an FPS counter, your own tool windows CoreEditor, ImGuiWrapper
Gameplay helpers Colliders, mouse hover, a 2D movement action GameplayFramework
Basics Logging, a reference-counted pointer, frame timing Log, Memory, CoreTypes

How these pages are organized

  • Using Janus gets you from a fresh checkout to a running game, and lists what every game needs.
  • Engine modules has a page per module. Each one opens with How to use, then explains the details, then lists the module's classes and functions.
  • Examples are complete programs. Every one is a single .cpp file that uses no image or data files, and every one has been compiled and run.
  • Code taken from the engine is marked Engine example. Code written for these docs by AI has no label, and its page starts with an AI-generated notice. See How to read these docs.
  • Links marked ↗ open the source on GitHub at the exact line, at the commit these docs describe.
