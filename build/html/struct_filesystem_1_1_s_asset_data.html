Filesystem::SAssetData Struct Reference
Filesystem

Everything the registry knows about one file: where it is, its asset path, name, extension, type and, once loaded, the loaded object. More...

#include <Filesystem/FilesystemTypes.hpp>

Overview

Created for every file at startup. Declared at include/Filesystem/FilesystemTypes.hpp:79.

How to use

Get one with Filesystem::GetAssetData(), read its fields, and pass it to Filesystem::Importers::LoadFile<T>() to load it. To add an asset made in code, create one with the default constructor, fill in AssetPath, AssetName, AssetType and ObjectData, and pass it to Filesystem::RegisterAssetData().

Asset dataexamples/modules/AssetsAndMemory.cpp

// GetAssetData accepts '/' or '\' separators.
// It logs an error and returns null if nothing matches.
const TObjectPtr<Filesystem::SAssetData> data =
Filesystem::GetAssetData("Shaders/Compiled/PullSpriteBatch.vert");
if (data.IsValid()) {
Log::Assets::Info("Name: {} Extension: {} File: {}",
data->AssetName, data->AssetExtension,
data->AssetFilePathRaw.string());
}
