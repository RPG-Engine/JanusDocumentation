Filesystem::SSoftAssetPath Struct Reference
Filesystem

A reference to an asset by its path. More...

#include <Filesystem/FilesystemTypes.hpp>

Overview

Cheap to copy and store in components; nothing is loaded until you ask.

Converts implicitly from a string, a loaded asset, or an Filesystem::SAssetData, and back to std::string. GetAssetData() looks the path up in the registry. Declared at include/Filesystem/FilesystemTypes.hpp:116. Registered with flecs, so the Entity Debugger shows it as a drop-down of every asset.

Register runtimeexamples/modules/AssetsAndMemory.cpp

// Assets can be registered at any time.
// The renderer uploads a texture the first time it is drawn.
// Asset paths use the platform's preferred separator ('\' on Windows), like
// the paths of scanned files. GetAssetData() converts '/' for you, but
// Filesystem::IsValid() (used by the renderer) does not.
std::filesystem::path checkerFile = "Generated/Checker";
const std::string checkerPath = checkerFile.make_preferred().string();
RegisterCheckerTexture(checkerPath, 64, 8);
const bool bValid = Filesystem::IsValid(Filesystem::SSoftAssetPath(checkerPath));
Log::Assets::Info("{} valid: {}", checkerPath, bValid);
