Overview

template<typename TValueType>
struct Input::SInputBinding< TValueType >

Usually written as {SDL_SCANCODE_W, value} inside the list passed to AddInputBindings_*. For bool actions the value can be left out: SInputBinding<bool>(SDL_SCANCODE_SPACE). Declared at include/Input/InputTypes.hpp:47.
