# Using Janus {#using_janus}

<p class="lede">Everything you need to go from a fresh checkout to a game that compiles and runs.</p>

Read these in order the first time:

1. \subpage getting_started — what to install, how to build the engine, and how to build and run the examples.
2. \subpage first_game — create your own game project and get a sprite on screen.
3. \subpage essentials — the rules every Janus game follows. Most "why is my screen black?" questions are answered here.

Then read \ref engine_organization to see how startup, the game loop and the modules fit together, and pick the \ref modules_overview "module pages" you need.

If something behaves oddly, check \ref known_issues.
